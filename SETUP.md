# Station Setup Guide

## 1. Equipment (starter)
- USB microphone kit ($30-70)
- Wired headphones
- Existing computer or phone
- Stable internet (test upload bandwidth)

## 2. Software
- Mixxx: https://mixxx.org/
- BUTT: https://danielnoethen.de/butt/
- OBS Studio: https://obsproject.com/
- Audacity for editing

## 3. Hosting Options (choose one)
| Option | Cost | Notes |
|--------|------|-------|
| Managed AzuraCast | ~$3-7/mo | Easiest, 100+ listeners |
| Self-host AzuraCast on VPS | VPS ~$4-10/mo | Full control, Docker |
| Free Icecast trial | $0 limited | For private tests only |

## 4. First Private Test
1. Install Mixxx + BUTT.
2. Create a short rights-cleared playlist.
3. Point BUTT to your stream server.
4. Listen on a second device.
5. Record the test.

## 5. Website
This repo is a static site. Deploy to GitHub Pages, Cloudflare Pages, or Vercel.

Enable GitHub Pages: Settings → Pages → Source: main branch / root.
